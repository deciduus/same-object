# How to argue with this vault

This is an open research vault, not finished work. Disagreement is the point.

- **One claim per Issue.** Name the note ID (C5, G25, ...) in the title. Say what is wrong and what would fix it.
- **Numbers need a source.** A count or a citation number must name the provider and the date it was fetched. Same rule we hold ourselves to.
- **Pull requests welcome.** Run `python vault/_lint.py` and `check.ps1` before you open one. Corrections go in `vault/log.md`, never silently.
- **Standings live in the vault.** `vault/00-index.md` is canonical. `ARCHIVE-findings-2026-09.md` is history.
- **Discussions** are for "have you seen this paper" and softer leads.

The most useful thing you can do: find the prior statement of a result we graded NOVEL. Every such grade lists the queries we ran. Beat the search.
