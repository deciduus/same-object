# Was the schema itself biased toward demolition?

> A method note about this project's own machinery, prompted by the user noticing the tone had
> gone negative. **The tone was downstream of the data model.**

## The observation

Every machine field in a gap note measures **whether a claim survives**: `standing`, `evidence`,
`contact-surface`, `crosses`. There was **no field, anywhere, for what a finding opened.**

So the vault could only record damage. Reports generated from it read as a demolition log —
*refuted, narrowed, withdrawn, wrong* — even in sessions where the substantive output was two new
theorems and a named experiment.

The work was not negative. **The instrument only had one dial.**

## Why it matters beyond tone

This is the same failure the project already named twice, turned inward:

- [[verdict-scoring]] — a taxonomy that let a label stand in for thinking
- [[relationship-description]] — replaced it, but only for *closing* judgements

An instrument that measures one thing will report that one thing, and the reporter will mistake
it for the terrain. **The withdrawal audit and this are the same error at different levels.**

## The fix, applied

A `question` note type and a `questions/` folder, with an `arises-from` edge pointing back at
what generated it. Six were harvested from a single session's findings — every one of them from
a result that had been filed purely as a loss:

| Filed as | Actually opened |
|---|---|
| feature 2 refuted | [[Q1-what-gets-checked]] — a better predictor |
| G1 damaged, theorem not unread | [[Q2-independent-rediscovery]] — a countable class |
| G4 bibliography wrong | [[Q3-theory-cited-hardware-omitted]] — a measurable bias |
| CDHM law defective | [[Q4-healing-needs-a-new-law]] — three testable candidates |
| C5 has limits | [[Q5-restless-patches]] — the case biology actually cares about |

## The open question

**Is one door opened per gap damaged the natural rate, or an artefact of looking for the first
time?** Six questions came out of one session's worth of demolition, which suggests the earlier
audits were also generating them and nobody was writing them down.

Worth a pass back over the corrections log to see how many were dropped.
