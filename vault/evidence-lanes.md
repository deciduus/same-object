# Evidence lanes — no lane gets 100% trust

> The user's doctrine, stated cleanly: **verification is non-negotiable, and no single lane of
> evidence earns total trust — because every lane carries a characteristic bias, including
> peer-reviewed academic science.** This is not relativism. Logic and honest method are the
> referee across all lanes; bias-awareness *sharpens* verification, it does not dissolve it.

## The disagreement is never "verify vs don't"

It is: *which lanes count, and at what weight?* Trusting one lane at 100% is itself a bias. The
project has proven this against its own home lane — see [[Q1-what-gets-checked]],
[[Q8-the-invisible-population]], the four confirmed unread theorems, and its own 578-reference
error. The published record is a filter with known blind spots, not a synonym for truth.

## The four lanes, each with its bias named

| Lane | Strong at | Characteristic bias |
|---|---|---|
| **Peer-reviewed academic** | reproducible mechanism; calibrated instruments | the publication filter — [[Q1-what-gets-checked]] economics, [[Q8-the-invisible-population]], positive-result bias, fields not reading each other |
| **Official / documentary** (declassification, gov reports) | provenance; primary sources | what an institution chooses to *release* and how it *frames* it (AARO's framing is contested — see [[disclosure-ledger]] row 16) |
| **Credentialed testimony** | a real firsthand *observable* | self-selection (who goes public), narrative reinforcement, specification/mechanism confusion — [[testimony-taxonomy]] |
| **Traditional / oral / independent** | observations the academic lane never logged | transmission drift, no instrumentation record (METHOD §13) |

## The referee — convergence across orthogonally-biased lanes

A claim upgrades toward true **not** by authority within a lane, but when **independent lanes
whose biases point in different directions converge on the same checkable observable.** That is
the same logic as the project's strongest tools:

- [[reservoir-audit]] — a specification is trusted when independent conservation books all balance.
- [[Q7-same-class-prediction]] — the bias-immune conditional: adding hidden cases can only
  strengthen it, because the lanes fail in the same direction.
- [[citation-sources]] — Crossref and OpenCitations agreeing is the check, precisely because they
  are independently assembled.

Convergence of orthogonal biases is signal. Agreement *within* one biased lane is not.

## The guard against relativism

This does **not** say all lanes are equal, or that logic is optional. It says the opposite: because
every lane is biased, **the method — reproducible check, stated provenance, specification-vs-
mechanism, orthogonal corroboration — is the only thing that is not.** Weakening a claim because
it lives in a biased lane is fair; strengthening a claim because it lives in a *prestigious* lane
is the error. The referee is the method, applied identically everywhere.

## How it changes the work

- No zero is trusted on one lane. The [[reading-not-counting]] grade already encodes this: a
  citation count and a full-text read fail differently, so a finding is strongest having survived
  both.
- Testimony and declassified records are admitted as evidence **at their tier** ([[testimony-taxonomy]],
  [[disclosure-ledger]]) — logged and specified, never mistaken for mechanism.
- The academic lane is admitted the same way: strong, and checked for its own blind spots, not
  waved through on prestige.
