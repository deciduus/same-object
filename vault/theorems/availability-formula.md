# Availability, A = MTBF/(MTBF+MTTR)

> **Not analogous to the photosystem repair steady state — algebraically identical to it.**

For a two-state system:

    A = MTBF/(MTBF+MTTR) = (1/k_damage)/[(1/k_damage)+(1/k_repair)] = k_repair/(k_repair+k_damage)

That is a derivation, not a coincidence, and it closes the formal half of [[G5-repair-number]].

Computed out in [[C1-availability-living-tissue]] — the first availability figures ever
calculated for biological tissue.
