# How passive is it?

> Passive dynamic walking, passive radiative cooling, morphological computation, compliant mechanisms — domain-local names, no shared name, no portable metric.

All four calibrate strongly; every crossing zero **except** passive dynamic walking against
morphological computation, which returns **2 real bridges** inside embodied robotics. The "no
contact" claim is overstated there.

**Best find:** IAEA-TECDOC-626 (1991) already defines an ordinal degree-of-passivity ladder,
Category A through D. Generalized: *the fraction of the response that survives when the
actuation path is cut.*

**Sub-claim UNVERIFIED.** Whether that ladder is invisible outside nuclear engineering cannot be
tested by term — "passivity" is a four-way homograph. It needs citation tracing, and the lookup
rate-limited before completing. **Open work.**
