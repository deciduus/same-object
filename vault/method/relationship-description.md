# Relationship description

Replaces the [[verdict-scoring]] taxonomy (HOLDS / WEAKENED / COLLAPSED), which forced
choices the evidence did not support and let both agents and author stop thinking at the
label.

**The object of study is not "is there a gap, yes or no."** It is: *what is the actual
relationship between these two literatures, and what would change it?*

## The six fields

Every entry in [[00-index]] is described along these. Counts are **inputs**, never verdicts.

### 1. Contact surface
How many papers genuinely touch both, and are they substantive or incidental? A count with
uninspected titles is not evidence. Report the number **and** what the papers actually are.

### 2. What crosses
Rank, weakest to strongest:

- **A shared word** — the fields use the same term for different things. See [[homographs]].
- **A metaphor** — one field gestures at the other without importing anything.
- **Vocabulary** — terms transfer, machinery does not.
- **The formalism** — equations transfer. This is a real bridge.
- **Data** — the strongest, and rarest.

### 3. Direction
Who reads whom. **One-way borrowings are common and a symmetric count hides them.** Ant
colony optimisation borrowed from ants; ant biology does not read optimisation. That is not
a gap or a bridge — it is an asymmetry with a direction.

### 4. Topology
Direct contact, or mediated? [[G28-marginal-value-gittins]] is the case that forced this
field: eight co-citers, **all eight neuroeconomics**. Two fields with zero direct contact,
joined only by a third that reads both and tells neither.

### 5. What is specifically absent
Not "a gap." The **named missing object** — a metric, a theorem, a translation, a
measurement. If you cannot name it, you have not found anything.

### 6. What would change it
The concrete move. Usually one of: supply a theorem that fixes a denominator (see
[[what-closes-a-gap]]), compute something nobody has computed, or carry a formalism across.

## The symmetry rule

**A withdrawal must meet the same standard as the finding it overturns.**

Discovered by failing it. Findings required calibration, multiple formulations and a
homograph check. Withdrawals initially required one query returning nonzero. That asymmetry
is the same bias this project documents elsewhere in physics measurement, turned inward.

Specifically, counter-evidence must:

- address the **actual claim**, not a neighbouring one — see [[G12-latch-fatigue]], where
  fatigue data for a spring *material* was used to withdraw a claim about a *latch*;
- be **read**, not counted — see [[G17-overconfident-uncertainties]], where 279 citations
  were treated as refutation without asking how many engaged the specific claim.

## Why counts still matter

They are the evidence. [[co-citation-audit]] turned this project from pattern-noticing into
measurement, and that was the single biggest methodological gain. The error was not
measuring — it was letting a measurement become a verdict without a description in between.
