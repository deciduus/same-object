# Verdict scoring — retired

The HOLDS / WEAKENED / COLLAPSED taxonomy. Replaced by [[relationship-description]].

## Why it was retired

**It forced choices the evidence did not support, and let both agents and author stop
thinking at the label.**

Two specimen failures:

- [[G12-latch-fatigue]] — the honest description is *"fatigue is characterized for the spring
  material, not for the latch contact."* The taxonomy had no slot for that, so it became
  WITHDRAWN and the actual finding was flattened out of existence.
- [[G17-overconfident-uncertainties]] — *"widely cited outside its domain, barely engaged
  within it"* teaches you something. "COLLAPSED" is a scoreboard entry that ends thought.

## The deeper problem

Once a verdict slot exists, the work becomes filling it. A binary in/out score is a shortcut
around thinking — and it produced an **asymmetric evidence standard**, where findings needed
calibration and multiple formulations while withdrawals needed one query returning nonzero.

That asymmetry is the same bias this project documents in physics measurement, turned inward.

## What is kept

The counts. They were the biggest methodological gain the project made — see
[[co-citation-audit]]. The error was letting a measurement become a verdict with no
description in between.
