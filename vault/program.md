# The program

> reports on 2026-09-05, tagged and costed. Working notes: `audits/program-synthesis-2026-09-05.md`.
> Nothing here is a new idea; every row traces to a note that already says the thing is missing.

`DATA` open dataset/API + an unrun computation · `PREDICTION` derived claim + named test ·
`INSTRUMENT` the audits on an open case, or a control they lack · `SIMULATION` a model never run
forward · `BUILD` bench/rig/tooling · `METHOD` instrument repair · `THREAD` an open question whose
closer is an unattempted computation. Owner: `agent` (desk/API) · `library` (ASU login, ILL, author
or industry contact) · `bench`. Access: `open` · `ASU` · `paywalled` · `not found` · `industry`.

## 3 · What the vault is actually about

The pattern across ~50 graded results is blunt: **the moves that produced new claims were the ones
that started from data, and the moves that produced prior art were the ones that started from a
resemblance between two famous objects.** Every same-object comparison run on a well-known pair came
back repackaged or rediscovered — the moving coupling point was thermoacoustics, Kedem–Caplan was in
active use, the healing Damköhler number is the Erlang-B complement of an M/M/1/1 loss system, the
soil `Ha` is the erosion-to-formation ratio soil science has published since Montgomery 2007 and
Verheijen 2009, and the grid-versus-bird reserve recursion is ruin theory on both sides with the
demand-side reading already standard grid practice. That is not bad luck: a famous pair is famous
because people have looked at it, so the prior is that the identity has already been written. What
actually produced new claims were computations nobody had run because the join was tedious rather
than deep — C43 joining OCTOPUS ¹⁰Be denudation to SSURGO `tfact` through a point-in-polygon query,
C38 putting nineteen species on one energy-margin axis and finding the sorting variable is a movable
metabolic setpoint rather than taxon or mass, C29 fitting a Weibull to 221 right-censored recovery
records, C28 noticing that the base-rate term astrobiology needs is an empty column rather than a
wrong number — together with the ruin-theory-style parent find, where the contribution is naming the
older formalism that two fields both re-derived without citing. Those survive because the object is a
number somebody else can recompute, not a resemblance somebody else has already noticed. The honest
tally is three novel results against roughly twenty repackagings and twenty located gaps, and a
located gap is real work that is not novelty. So the vault is not a catalogue of unifying principles;
it is **a working instrument for finding computations that are cheap, unrun, and checkable**, plus a
corrections log that is the most trustworthy thing in it. The programme above is weighted
accordingly: 52 DATA items against 11 same-object THREAD items, because that is where the evidence
says the yield is.
