# Sources/citation audit

## Summary (5 lines max)
Provenance is bimodal: `vault/sources/` extracts are exemplary (URL, byte count, HTTP status, fetch date, extraction tool, verbatim flag), while the gap notes — where the headline claims live — name almost no reproducible procedure.
Not one of the five `evidence: citation-intersection` gaps states the full tuple (anchor DOI + provider endpoint + query date + N + coverage denominator); G25, the "strongest finding," names no database and no anchor DOI at all.
Web verification: 5 VERIFIED, 1 NOT FOUND (Griebling 2026), 3 CONTRADICTED — and two contradictions land on the project's own *corrections*, not its original claims.
The flagship lesson "578 was wrong, it is really 595" is itself a provenance error: Crossref's deposited `reference-count` for that DOI is exactly **578**. The two numbers measure different objects (deposited list vs printed bibliography).
The 578-class error is live right now in a second place: `theorems/stress-strength-interference.md` withdraws "46 citations" and "753 works" as stale/artifacts while `gaps/G19` still asserts both as fact.

## Findings

- [vault/gaps/G25-proofreading-coding.md] HIGH — the gap graded `citation-intersection` and billed as "the project's strongest finding" names no database, no endpoint, no anchor DOI, no query date and no query string; only bare counts (1,463 / 416 / 16) — compare `vault/sources/*.md`, which record HTTP status and byte counts for a PDF — add a Provenance block with anchor DOIs, provider endpoint, pull date, and the literal `"proofreading" AND "rate-distortion"` query plus its host.
- [vault/gaps/G25-proofreading-coding.md] HIGH — coverage is 416/1,463 = 28.4%, yet the frontmatter says "1,463 citers pulled and bibliographies intersected" — G6 in the same vault argues that 77.5–100% coverage "is what makes a zero a finding"; G25 misses its own vault's bar by ~3x and never says so — state coverage as a headline caveat and re-run to raise it.
- [FINDINGS.md, METHOD.md, vault/log.md, vault/method/co-citation-audit.md, vault/gaps/G4] HIGH — the 578→595 correction is framed as "an unverified figure propagated into five files before anyone opened the source", but 578 is Crossref's deposited `reference-count` for the DOI — live fetch returns 578 — reword to: deposited list 578 vs printed bibliography 595, two different objects; the actual defect was never naming the source of 578. As written, the project's flagship methodological lesson mis-diagnoses its own failure.
- [vault/gaps/G19-safety-factor-derived-twice.md vs vault/theorems/stress-strength-interference.md] HIGH — direct intra-vault contradiction: G19 asserts "46 citations. All 46 were fetched and inspected" and "753 works"; the theorem note withdraws both — both files carry `last-checked: 2026-09-03`, and OpenAlex externally returns 46 — reconcile in one place with a provider beside each count and propagate. This is the 578 failure mode recurring, uncaught.
- [vault/gaps/*.md] HIGH — no gap records a query date distinct from `last-checked`, and all 19 gaps carry the identical `last-checked: 2026-09-03` — a single vault-wide date cannot distinguish "re-verified today" from "inherited" — add a per-claim `retrieved:` date inside evidence blocks.
- [vault/gaps/G4-criticality-as-design.md, G6-multifunctionality.md, G9-discrepancy-base-rate.md] MED — `evidence:` disagrees with the `evidence/*` tag in the same frontmatter: G4 `full-text-read` vs `evidence/single-review`; G6 `citation-intersection` vs `evidence/full-text-read`; G9 `full-text-read` vs `evidence/string-protocol` — found by parsing all 19 gap files — `vault/_lint.py` validates vocabularies but never cross-checks tag against field.
- [vault/gaps/G28-marginal-value-gittins.md] MED — four mutually inconsistent Gittins-citer denominators (1,013 / 1,010 / 1,542 / 5,424) plus a self-flagged method-dependent control (181 vs 24) — Crossref says 986 — tabulate one denominator per provider per date and delete the rest.
- [vault/gaps/G28, vault/00-index.md, vault/log.md] MED — Griebling 2026 is hedged as "Not obtained; an outstanding check" in the body but asserted as fact in the frontmatter `note` and the index one-liner — frontmatter is what the index renders, so the hedge is invisible where it is read — propagate the hedge or drop the claim.
- [vault/gaps/G17-overconfident-uncertainties.md] MED — "roughly six across forty years" is the load-bearing number and has no procedure: no screening rule applied to the 279, no list, no inclusion criteria; only four exemplars are named — body text — state the screening protocol and list all six with DOIs.
- [vault/gaps/G21-dimensionless-regime-map.md] MED — graded `full-text-read` but contains no URL, DOI or accession for any source; Vogel quotes lack edition and page numbers; the Ortega Π values are self-marked UNVERIFIED (ScienceDirect 403, Europe PMC 503) — it is the only gap file with zero procedure markers of any kind — add locators or strike the figures.
- [vault/gaps/G8-energy-per-bit-axis.md, vault/gaps/G27-collective-decision.md] MED — both are `string-protocol` and both are *overturned* on bare string counts (575, 26, 551) with no host or date — the instrument the project says fails >50% on re-test is used to retract as confidently as it was used to assert — require host + date for any overturning count, and re-check under citation intersection before treating `overturned` as final.
- [vault/method/citation-intersection.md] MED — "Eight surviving gaps have never faced this test. Listed in [[00-index]]" — `00-index.md` contains no such list (grep returns nothing) — add the list or remove the pointer; a dangling accountability promise is worse than none.
